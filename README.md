# Cangjie Community

## Method of Obtaining Full Cangjie Code

The full code repositories are organized as follows：

```
manifest
    └── default.xml
    └── cangjie
        └── cangjie.xml
```

- All code repositories can be download form the default.xml file.
- Download Method: repo init -u *URL* -b dev

Default value of URL is https://gitcode.com/Cangjie/cangjie_manifest.git or git@gitcode.com:Cangjie/cangjie_manifest.git
